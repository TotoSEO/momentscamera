# Sources consultées

Les recherches menées pour construire ce projet, regroupées par sujet.

## Le produit

La page fournisseur transmise (`french.alibaba.com`) est protégée par un
captcha et illisible par script ; les données ont été récupérées sur la
fiche `.com` équivalente et recoupées avec les descriptifs revendeurs du
même modèle, puis avec les visuels fabricant fournis en cours de projet.

- [Fiche Alibaba du produit](https://www.alibaba.com/product-detail/Mini-Keychain-Camera-Photo-Video-1080P_1601806083220.html) — nom, coloris, paliers de prix, fournisseur
- Descriptifs revendeurs du G6 Mini Thumb Camera — écran TFT 0,96", objectif 130°, autofocus, USB-C, 26 g, neuf coloris
- Visuels fabricant (fournis par le client) — forme réelle : plaquette horizontale, balayage arc-en-ciel, mention « 1984 », objectif décentré, écran au dos
